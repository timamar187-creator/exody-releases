# Exody

**The AI workbench for your Mac** — code agent, mail/calendar assistant, design studio, and The Exody Router: smart per-task model routing that cuts your AI bill on every run.

## Download

Grab the latest release from the [Releases page](https://github.com/timamar187-creator/exody-releases/releases/latest):

1. Download `Exody-<version>.zip`
2. Unzip, open the DMG
3. Drag **Exody** to Applications

Universal build — Apple Silicon and Intel.
